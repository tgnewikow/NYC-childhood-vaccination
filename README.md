# Childhood vaccination in New York City
For this project, I analyzed [childhood vaccination data](https://www.nyc.gov/site/doh/data/data-sets/childhood-vaccination-data.page) from NYC Health using the pandas Python library. I used Datawrapper make charts of my findings and created a webpage using HTML and CSS.

I also interviewed NYC Health Acting Commissioner Dr. Michelle Morse to recieve more background about childhood vaccination in New York City and how the health department is addressing disparities in vaccination rates. 

Key takeaways in the data are that vaccination rates in the city vary across vaccine type, race and neighborhood.
